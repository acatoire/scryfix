# Scryfix

*A community tool for reporting and fixing data errors on Scryfall.*

## Description

### Short description

> A wizard-driven tool that turns Scryfall data errors (missing/mislabeled
> images, unlisted printings, and more) into clean, structured reports —
> submitted as GitHub PRs so the community and third-party MTG tools can
> review and consume fixes directly. Unofficial, not affiliated with
> Scryfall.
